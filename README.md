# Physics Classroom Simulations

Interactive, parameter-driven physics demonstrations for a classroom display.

The top navigation groups experiments into Waves, Refraction, Physical Optics, Imaging, Mechanics, Electromagnetism, and Astronomy. Select an experiment within each group. The URL hash (for example, `#lab=film` or `#lab=prism`) opens a specific experiment directly.

Refraction includes Snell's law, total internal reflection, a continuously refracting hot-road mirage, primary-rainbow ray paths, prism dispersion, Brewster polarization, and atmospheric optics. Spherical aberration is grouped with Imaging and now compares the perceptual blur from full and stopped-down apertures. Physical Optics includes double-slit interference, single-slit diffraction, and thin-film interference with a thickness-dependent diagram and phase markers.

Electromagnetism includes an idealized cyclotron, a crossed-field velocity selector, and a mass spectrometer. The cyclotron uses nonrelativistic proton dynamics, magnetic half-orbits, and an RF energy kick only at each gap crossing; detuning the RF changes the kick phase. The selector numerically integrates the Lorentz force for singly charged 200 u ions, including plate impacts and the exit slit. The spectrometer chooses `v = E/B1`, then compares semicircular paths at `r = mv/(qB2)` for ions differing by 2 u. Horizontal and vertical drawing scales may differ to keep deflections visible. Astronomy offers heliocentric and geocentric vector views of the same observed retrograde path; the circular-orbit geocentric decomposition is exact for that circular model, but it is not a full historical Ptolemaic model. All experiment canvases have a full-screen presentation control.

Atmospheric color controls are teaching approximations, not weather forecasts. In particular, the storm-cloud colors are qualitative: a green or purple sky does not diagnose a tornado. The mirage refractive-index contrast and the apparent rainbow-droplet size are visually enlarged; their captions state which dimensions are schematic.

Reference points for classroom review: [NWS rainbow optics](https://www.weather.gov/fgz/Rainbow), [Harvard hot-road mirage demonstration](https://sciencedemonstrations.fas.harvard.edu/presentations/hot-road-mirage), [NOAA sky color](https://www.nesdis.noaa.gov/about/k-12-education/atmosphere/why-the-sky-blue), [NASA stellar scintillation](https://starchild.gsfc.nasa.gov/docs/StarChild/questions/question26.html), and [OpenStax magnetic spectrometer and cyclotron](https://openstax.org/books/university-physics-volume-2/pages/11-7-applications-of-magnetic-forces-and-fields).

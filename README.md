# Physics Classroom Simulations

Interactive, parameter-driven physics demonstrations for a classroom display.

The top navigation groups experiments into Waves, Refraction, Physical Optics, Imaging, Mechanics, Electromagnetism, and Astronomy. Select an experiment within each group. The URL hash (for example, `#lab=film` or `#lab=prism`) opens a specific experiment directly.

Refraction includes Snell's law, total internal reflection, atmospheric optics, prism dispersion, Brewster polarization, and spherical aberration. Physical Optics includes double-slit interference, single-slit diffraction, and thin-film interference.

Electromagnetism includes an idealized cyclotron and a crossed-field velocity selector. The cyclotron uses nonrelativistic proton dynamics, magnetic half-orbits, and an RF energy kick only at each gap crossing; detuning the RF changes the kick phase. The selector numerically integrates the Lorentz force for singly charged 200 u ions, including plate impacts and the exit slit. Its horizontal and vertical drawing scales differ so deflection remains visible on a classroom display. All experiment canvases have a full-screen presentation control.

Open `index.html` locally, or use the [GitHub Pages site](https://chianghunghsuan.github.io/physics-sim/).

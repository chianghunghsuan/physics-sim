高中物理現象模擬器

把課堂上最需要「看見過程」的物理現象放在同一頁：波動、光學、力學與行星運動都能調參數、暫停與慢速播放，方便在電子白板上逐步打開重點。

駐波疊加

先選左右兩端是固定或自由，再逐步打開入射波、反射波與疊加結果。追蹤點會跟著同一個相位前進，直接看波速與固定端反相。

λ右 = 1.00 mλ = v / f
Δf = 0.00 Hz同頻時圖形穩定
振幅比 = 1.00等振幅才有真正節點
固定-固定正常模態L = nλ/2
固定－固定 兩端都是節點；fₙ = nv/(2L)
固定－固定的完美駐波 fₙ = nv/(2L)

講法：先讓學生只看藍色向右波，確認「波形在移動、質點上下振動」。再打開橘色反射波，最後打開綠色疊加，讓節點從相消而來，不是憑空出現。

強調：同頻、等振幅只保證干涉圖形穩定；還要同時符合左右兩端的節點或腹點條件，才是這段弦的正常模態。

都卜勒效應

切換波源移動或觀察者移動。波源模式會逐次留下「發波位置」：波源先在某處發出一圈波，移動到下一個位置後再發下一圈，因此前方波面自然被壓縮、後方波面自然被拉開。

波面 波源 觀察者 震波錐
原波長 = 10.00 mλ = v / f
觀察頻率 = 1.40 Hz接近時變高
f'/f = 1.00比較音調高低
波源靜止或等效靜止波面間距左右相同

講法：先選「波源移動」，指著橘色小點說明每一圈波面都是從過去的位置發出的；再看現在的波源已經往前走，所以前方波面中心彼此更近。接著改成「觀察者移動」，比較波面沒有被壓縮時，觀察者仍會因為穿越波峰速率改變而聽到頻率不同。

強調：介質中的波速由介質決定。都卜勒效應改變的是觀察到的頻率與波長，不是聲波在空氣中的速率。

水波槽雙源干涉

兩個同調點波源連續發波。水波槽的亮暗直接表示水面狀態：波峰亮、波谷暗，固定腹線標成淺藍色、固定節線標成灰色。

波峰（亮） 波谷（暗） 節線（灰） 腹線（淺藍）／同相交點
波長 = 54 px波面間距
d/λ = 2.96源距越大，節線越多
相位差 = 0°同相時中央為腹線
同相雙源中央線建設性干涉

講法：先只看瞬時水面，確認亮帶與暗帶都會向外移動；再依序打開淺藍腹線與灰色節線，區分「水面正在亮或暗」和「振幅長期最大或為零」。

強調：調大波源距離或調短波長，會讓路徑差容納更多半波長，因此腹線、節線都會增加。若 d/λ 只接近整數，沿波源連線方向是近腹區，不一定有精確腹線。

雙狹縫干涉

預設採高中課程的理想雙狹縫模型：兩縫等寬、振幅相同且忽略單縫繞射，因此亮紋等距、等寬、等亮。需要比較真實情況時，再開啟進階包絡。

連續波面 同相交點 屏幕亮紋 進階繞射包絡
λ = 550 nm紅光較長、藍光較短
條紋間距 = 3.14 mmΔy = λD / d
d/λ = 636縫距越大，條紋越密
理想雙狹縫亮紋等距、等寬、等亮

講法：先維持理想模型，確認所有亮紋的中心等距、寬度相同、最大亮度相同；再調整波長、縫距或屏幕距離，看條紋只改變間距，不會由中央向外逐漸變暗。

強調：只有另外開啟單縫繞射包絡時，外側亮紋才會逐漸變暗；這是進階的有限縫寬模型，不是高中題目預設的理想雙狹縫。

惠更斯原理

把每個波前上的點都視為次波源。切換平面波、狹縫與障礙邊緣，觀察許多小圓波如何共同形成下一個波前。

入射波前 次波源 新波前包絡 障礙物
λ = 46 px次波半徑隨時間增加
開口 = 150 px開口越窄，繞射越明顯
次波源 = 13 個點越多，包絡越平滑
狹縫繞射通過開口的點成為次波源

講法：先用平面波模式，讓學生看到很多圓形次波的外切線仍然是平面；再切到狹縫，說明只剩開口上的點能繼續發出次波，所以波前自然向外彎。

強調：惠更斯原理不是另一個公式，而是一個建構波前的方法；反射、折射、繞射都可以用「每點都是次波源」來理解。

等速圓周運動與簡諧投影

圓周上的質點保持等速率，投影點卻沿直線來回加速。兩者共用相同相位，因此投影位移是正弦或餘弦函數。

等速圓周 轉動半徑 簡諧投影 速度 v 向心加速度 aᶜ
角速度 ω = 1.05 rad/s每秒轉過的角度
週期 T = 6.0 s圓周與投影週期相同
投影 x = 1.00 Ax = A cos θ
端點：速度為零加速度量值最大

講法：先盯著圓周質點，再沿虛線找到投影點；兩點總是同相。投影靠近端點時變慢，通過中心時最快。

強調：等速圓周運動的「速率」固定，但速度方向持續改變；簡諧投影的速度與加速度量值都會改變。

陀螺進動與角動量方向改變

重力矩不直接把高速旋轉的陀螺壓倒，而是持續改變角動量的方向，使轉軸繞鉛直方向進動。

角動量 L 力矩 τ 進動軌跡
角動量 L = 2.51 kg·m²/sL = Iω
重力矩 τ = 4.25 N·mτ = mgr sin α
進動角速度 Ω = 1.95 rad/sΩ = mgr/L
進動週期 = 3.22 s轉得越快，進動越慢

講法：先暫停並比較藍色 L 與紅色 τ：τ 幾乎垂直於 L，所以主要改變方向而不是立即消除自轉。再播放觀察 L 的尖端沿圓周移動。

強調：增加自轉速率會增大 L，因此相同重力矩每秒能改變的方向較少，進動反而變慢。陀螺受到外力矩，所以陀螺本身的 L 方向會改變；把陀螺與地球視為整體時，總角動量才守恆。

定滑輪、動滑輪與滑輪組

固定相同拉繩速度，比較不同支撐繩股數。動滑輪省力，但自由端必須移動更長距離，負載才會上升相同高度。

繩索 負載 位移比較
支撐繩股 n = 2理想機械利益為 2
所需拉力 F = 98.0 NF = mg/n
拉繩距離 = 2.00 m負載上升 1.00 m
完成時間 = 5.00 s同拉繩速度下，省力但費時

講法：保持拉繩速度不變，只切換 n=1、2、4。學生會直接看到負載越省力，上升得越慢；右側位移尺則顯示自由端走了負載的 n 倍距離。

強調：理想滑輪沒有省功：Fs = mgh。省下多少力，就要多拉相同比例的距離與時間。

地心說與日心說如何描述行星逆行

左側用地球追越外行星解釋逆行；右側把相同的相對位置拆成均輪與本輪。兩種畫法得到相同視方向，但需要的結構不同。

太陽 地球 外行星 視線／視位置
觀測火星外行星公轉週期 1.88 年
目前：逆行視黃經正在減少
地球視方向 = 0.0°兩種模型完全相同
2 個日心圓 ↔ 均輪＋本輪簡化等速圓模型

講法：先看左側：地球較快，在會合附近超越外行星，視方向短暫反轉。再看右側：地心模型以均輪中心繞地球、行星再繞本輪，也能造出完全相同的相對位置。

強調：「能解釋」不等於模型同樣簡潔。簡化圓軌道下，日心模型用地球與行星各自繞太陽；地心模型要為每顆行星配置均輪、本輪及相位關係。

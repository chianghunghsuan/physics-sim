高中物理現象模擬器

把課堂上最需要「看見過程」的物理現象放在同一頁：波動、光學、力學、電磁學與行星運動都能調參數、暫停與慢速播放，方便在電子白板上逐步打開重點。

都卜勒效應

切換波源移動或觀察者移動。波源模式會逐次留下「發波位置」：波源先在某處發出一圈波，移動到下一個位置後再發下一圈，因此前方波面自然被壓縮、後方波面自然被拉開。

講法：先選「波源移動」，指著橘色小點說明每一圈波面都是從過去的位置發出的；再看現在的波源已經往前走，所以前方波面中心彼此更近。接著改成「觀察者移動」，比較波面沒有被壓縮時，觀察者仍會因為穿越波峰速率改變而聽到頻率不同。

強調：介質中的波速由介質決定。都卜勒效應改變的是觀察到的頻率與波長，不是聲波在空氣中的速率。

兩個同調點波源連續發波。水波槽的亮暗直接表示水面狀態：波峰亮、波谷暗，固定腹線標成淺藍色、固定節線標成灰色。

講法：先只看瞬時水面，確認亮帶與暗帶都會向外移動；再依序打開淺藍腹線與灰色節線，區分「水面正在亮或暗」和「振幅長期最大或為零」。

強調：調大波源距離或調短波長，會讓路徑差容納更多半波長，因此腹線、節線都會增加。若 d/λ 只接近整數，沿波源連線方向是近腹區，不一定有精確腹線。

強調：只有另外開啟單縫繞射包絡時，外側亮紋才會逐漸變暗；這是進階的有限縫寬模型，不是高中題目預設的理想雙狹縫。

單狹縫繞射

平面波只從一條有限寬度的狹縫通過。狹縫內各點依惠更斯原理發出次波，屏幕上的光強由這些次波的相位疊加形成。

λ = 550 nm波長越長，繞射越明顯
a/λ = 182縫越窄，中央亮紋越寬
第一暗紋 θ₁ = 0.32°sin θ₁ = λ/a
中央亮紋寬 = 22.0 mm約為兩側亮紋寬的 2 倍

講法：先看狹縫內一排同相次波源；中央方向路徑差為零，所以全部相加。偏離中央後，各點逐漸不同相，第一暗紋恰好能把狹縫配對成互相抵消的兩半。

強調：單狹縫中央亮紋從第一個負暗紋跨到第一個正暗紋，因此寬度約為其他亮紋的兩倍；兩側亮紋也會快速變暗。

惠更斯原理

把每個波前上的點都視為次波源。切換平面波、狹縫與障礙邊緣，觀察許多小圓波如何共同形成下一個波前。

講法：先用平面波模式，讓學生看到很多圓形次波的外切線仍然是平面；再切到狹縫，說明只剩開口上的點能繼續發出次波，所以波前自然向外彎。

強調：惠更斯原理不是另一個公式，而是一個建構波前的方法；反射、折射、繞射都可以用「每點都是次波源」來理解。

圓周上的質點保持等速率，投影點卻沿直線來回加速。兩者共用相同相位，因此投影位移是正弦或餘弦函數。

第二階段：學生確認兩個影子的位置後，再打開位移－時間曲線；此時只把相位攤開成時間，不再拿曲線端點冒充投影質點。

陀螺進動與角動量方向改變

重力矩不直接把高速旋轉的陀螺壓倒，而是持續改變角動量的方向，使轉軸繞鉛直方向進動。

角動量 L 力矩 τ 進動軌跡
角動量 L = 2.51 kg·m²/sL = Iω
重力矩 τ = 4.25 N·mτ = mgr sin α
進動角速度 Ω = 1.95 rad/sΩ = mgr/L
進動週期 = 3.22 s轉得越快，進動越慢

講法：先暫停並比較藍色 L 與紅色 τ：τ 幾乎垂直於 L，所以主要改變方向而不是立即消除自轉。再播放觀察 L 的尖端沿圓周移動。

強調：增加自轉速率會增大 L，因此相同重力矩每秒能改變的方向較少，進動反而變慢。陀螺受到外力矩，所以陀螺本身的 L 方向會改變；把陀螺與地球視為整體時，總角動量才守恆。

定滑輪、動滑輪與滑輪組

固定相同拉繩速度，比較不同支撐繩股數。動滑輪省力，但自由端必須移動更長距離，負載才會上升相同高度。

繩索 負載 位移比較
支撐繩股 n = 2理想機械利益為 2
所需拉力 F = 98.0 NF = mg/n
拉繩距離 = 2.00 m負載上升 1.00 m
完成時間 = 5.00 s同拉繩速度下，省力但費時

講法：保持拉繩速度不變，只切換 n=1、2、4、6。學生會直接看到負載越省力，上升得越慢；右側繩長表則顯示自由端走了負載的 n 倍距離。

強調：理想滑輪沒有省功：Fs = mgh。省下多少力，就要多拉相同比例的距離與時間。

折射、臨界角與全反射

光粒子沿著真正計算出的路徑前進；跨越介面時頻率不變，速度與波長隨折射率改變。入射角超過臨界角後，透射光消失並全部反射。

入射光 反射光 折射光 法線／角度
θ₁ = 45.0°；θ₂ = 28.1°n₁ sinθ₁ = n₂ sinθ₂
v₂/v₁ = 0.67頻率不變，波長跟速度同比改變
反射 5%｜透射 95%線條亮度依 Fresnel 比例呈現
一般折射光進入高折射率介質，向法線偏折

講法：先固定角度，只改 n₂，觀察下方光粒子的速度與波前間距同時改變。再切到「玻璃臨界角」，慢慢提高角度：折射光先貼近介面，越過臨界角後才完全消失。

強調：全反射要同時滿足由高折射率射向低折射率，以及入射角大於臨界角；不是任何反射都叫全反射。

大氣散射：藍天與紅色夕陽

讓紅、綠、藍光包沿同一路徑穿過大氣。小分子對短波長散射較強，所以側看天空偏藍；太陽接近地平線時路徑變長，直達眼睛的光則偏紅。

相對路徑 = 1.4太陽越低，穿越大氣越長

講法：先用正午藍天看藍色光包較常離開直射光束，再把太陽拉低。路徑變長後，更多藍綠光被散到別處，抵達觀察者的直射光逐漸變橘紅。

限制：為了讓課堂看得清楚，分子與散射事件被放大；顏色強弱仍依波長關係與目前大氣路徑計算。

磁煞車與渦電流

導體圓盤切過磁場時，磁通量的改變在盤內產生封閉渦電流。渦電流形成的磁場反抗原本的運動，動能最後轉為焦耳熱。

模型界線：方向、B² 與速度比例、材料及開槽效應依物理定律計算；圓盤內實際渦電流會是連續分布，此處用兩個主要迴路做教學化呈現，不宣稱是有限元素分析。

直流馬達：電流、受力與換向

電池先驅動線圈電流，磁場對兩側導線施加相反方向的力；分裂環換向器每半圈交換接點，使力矩持續朝同一方向。

上方用俯視軌道看誰追越誰；下方把地球固定在星空中央，直接畫出行星視位置何時折返。可切換等速圓軌道與克卜勒橢圓。

講法：先按「跳到逆行中心」。上方看地球與行星的相對視線，再看下方固定星空：綠線往右是順行，紅線折回就是逆行；不是行星真的在軌道上倒車。
